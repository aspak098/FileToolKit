# PDF & Image Toolkit — Starter

Working browser-first tools:
- Compress Image
- Resize Image
- JPG/PNG/WebP Converter
- Crop Image
- Image to PDF (multiple images)

Merge PDF is intentionally disabled in this starter until a dedicated PDF library is added.

Run by opening `index.html` or with VS Code + Live Server.

Before publishing: replace the canonical URL, add robots.txt, sitemap.xml, Privacy Policy, Terms, Disclaimer and Contact pages. Create separate SEO pages for individual tools.
